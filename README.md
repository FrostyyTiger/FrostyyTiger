# Marcell Bierbauer-Szigeti

Co-founder and CTO of Navigo Intelligence, a small self-funded software company near Zurich. Our construction-site product has had its first customer live in production since September 2026, and our tax-return workflow for Swiss fiduciary firms is at demo stage.

Two decisions say most about how I build: tenant isolation in Postgres row-level security rather than application code, and outward sends that wait for a person to confirm them. How it's built, and why: **[navigo-engineering](https://github.com/FrostyyTiger/navigo-engineering)**.

Coding agents write the code. I decide what gets built, write the specs and acceptance criteria, and I'm accountable for what ships.
